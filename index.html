Sobre o Projeto

Este é um projeto de demonstração para apresentar o uso do GitFlow e GitHub Actions.

O GitFlow é um modelo de ramificação para Git que facilita o desenvolvimento paralelo e a colaboração em equipe.

Recursos Implementados

  • Estrutura básica HTML, CSS e JS
  • Integração com GitHub
  • Pipeline CI/CD com GitHub Actions
